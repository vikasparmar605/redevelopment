## Derived finishes

- `rough_linen_ivory_diff_1k.jpg`: photographed blue linen diffuse desaturated and brightened by 1.30 to produce a neutral ivory dye; the photographed normal and roughness maps remain unchanged.
- `poly_wool_herringbone_ivory_diff_1k.jpg`: photographed wool diffuse with saturation multiplied by 0.20 and brightness by 1.80 for an oatmeal dye.
- `marble_01_ivory_diff_1k.jpg`: saturation multiplied by 0.22 and brightness by 1.28 for pale warm honed stone.
- `laminate_floor_02_honed_rough_1k.jpg`: roughness remapped to `0.35 + 0.60 × original` for oiled oak.
- `marble_01_honed_rough_1k.jpg`: roughness remapped to `0.40 + 0.45 × original` for a honed finish.

All derived files inherit their CC0 source status. Source files are preserved where supplied. The normals use the OpenGL convention. Diffuse images use sRGB; normal and roughness images use linear/no-color-space sampling. The JSON manifest records MD5 checksums; original files were verified against the official API checksums.

Texture dimensions use Poly Haven scan sizes: oak veneer 1.83 m, plank floor 1.70 m, rough linen 0.271 m, herringbone wool approximately 0.270 × 0.276 m, plaster 1.00 m, pale stone 1.50 m, bathroom stone 3.00 m.
